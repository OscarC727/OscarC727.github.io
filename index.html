    The Lower-Limb Exoskeleton

    Active

    I'm the controls lead for IEEE EXO, a student club building a lower-limb exoskeleton that assists hip and knee movement. I'm working on the gait-phase detection, a state machine driven by force sensors, and the CAN setup between the Teensy sensor boards and the Jetson.

    In the Balance

    Active

    A rotary inverted pendulum the controls team is building as practice before the exo, alongside the PID workshops I run. The code runs on Linux on the Jetson, same as the exo will.

  • Complete

    Audio Spectrum Analyzer

    Built

    Co-built with a friend. It shows live sound frequencies as bars on a TFT screen using an FFT on a Teensy. I wrote and debugged the code that turns the audio into the display.

    Teensy 4.0, ILI9341 display, C++
  • Complete

    Self-Stabilizing Spoon

    Prototype built

    A spoon that keeps itself level for people with hand tremors. An IMU reads the motion and my PID loop drives two servos to correct it. A teammate designed a custom PCB for it, and I'm porting the code to an STM32 next.

    ESP32 and XIAO ESP32, MPU6050, SG90 servos, C++
  • Complete

    N-bit ALU in Verilog

    Verified

    A parameterized ALU with 8 operations and carry, overflow, zero, and negative flags. My testbenches check every 8-bit input plus a million random cases at 64 bits, with zero failures. I also set up an open-source toolchain to program a Tang Nano 20K FPGA.

    Verilog, Icarus Verilog, Yosys, nextpnr
