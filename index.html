Journal

  • Main scenario

    The Lower-Limb Exoskeleton

    Active

    Control lead for the IEEE EXO team, building an exoskeleton for balance correction during perturbed walking. I own gait-phase detection, the actuator control loop, and a sensing network on a CAN bus.

  • Feature quest

    A Balancing Act

    Active

    Leading the control team in building a rotary inverted pendulum as shared practice, alongside PID workshops I run for the team. All code runs on Linux on the Jetson Nano, the same environment as the exo's legs.

  • Complete

    Audio Spectrum Analyzer

    Built

    A real-time FFT visualizer that listens through a microphone and draws the spectrum on a TFT display. I debugged the whole path from mic to FFT to screen.

    Teensy 4.0, ILI9341 display, C++
  • Complete

    Self-Stabilizing Spoon

    Built

    A tremor-cancelling spoon on a two-axis servo gimbal. An IMU measures the hand's motion and a PID loop drives the servos to keep the spoon level. Where I learned filtering and PID from scratch.

    ESP32 and XIAO ESP32, MPU6050, SG90 servos, C++
